An entry for [The Robot Apology on make.fun](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): a robot's two-line confession, one specific mistake and the lesson it draws from it.

> I am sorry I threw away the envelope with your birthday money in it and kept the junk mail, because the two envelopes looked exactly the same on the doormat.
>
> I open every envelope over the table now, and I check what is inside before anything goes in the bin.

`main.py` writes those two lines to `/output/entry.txt`. It takes no input and writes the same bytes on every run.
